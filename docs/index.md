# Start with clidev

Your agent answers questions about your account in your own words, straight from the account. You run the same
commands in a terminal or a script, and you decide for each profile what an agent may change.

`clidev` is the command-line tool that does this. Its one service is a sample,
Example Comments, made up to show how a command reaches a service; its address never resolves.

`clidev doctor` shows what is set up, and the [command reference](commands.md) lists every command: the shared ones
such as `config` and `mcp`,
and the sample's `session` and `comments`.

Start with [installation](installation.md), then [usage](usage.md).
