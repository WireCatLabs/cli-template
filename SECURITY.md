# Reporting a vulnerability

Please report a security problem privately — never in a public issue:

- by email: [hello@wirecat.dev](mailto:hello@wirecat.dev);
- or through [GitHub's private vulnerability reporting](https://github.com/WireCatLabs/clidev-cli/security/advisories/new).

Say what you saw, how to repeat it, and the version (`clidev --version`). Never send a token, a password or anyone's
private content.

What `clidev` keeps on your computer: the [shared security page](https://wirecat.dev/en/docs/security) and
[docs/security.md](docs/security.md).

Security audits of `clidev` follow the shared
[security method](https://github.com/WireCatLabs/cli-testing/tree/main/docs/security) in cli-testing.
